PACKAGES

Four ways to
get started.

01DMG

LimeCode App

The editor only. Choose this when you already have CLI and MCP, or only need the native app.

Download App DMG ↓
  1. Open the DMG.
  2. Drag LimeCode into Applications.
  3. Open LimeCode from Launchpad or Finder.
02DMG

LimeCode Complete

The recommended website bundle: LimeCode plus the CLI and MCP helpers for automation.

Download Complete DMG ↓
  1. Open the DMG.
  2. Drag LimeCode into Applications.
  3. Use the included helpers or install them with the commands below.
03PKG

CLI package

Installs limecode in /usr/local/bin so scripts and agents can control a running website edition.

Download CLI PKG ↓
  1. Open the PKG and follow the installer.
  2. Enter your macOS password when asked.
  3. Start the website edition of LimeCode before editing commands.
04PKG

MCP package

Installs the MCP stdio server in /usr/local/libexec for Claude Desktop and IDE agents.

Download MCP PKG ↓
  1. Open the PKG and follow the installer.
  2. Enter your macOS password when asked.
  3. Configure the MCP command in your agent.

App Store customers should use the App Store build for the editor. CLI and MCP are website-edition tools; the App Store build intentionally does not include automation. Verify SHA-256 checksums ↗

COMMAND LINE

Use LimeCode
from a terminal.

The CLI talks to the currently running website edition over a local Unix socket. Metadata commands work offline; document commands require LimeCode to be open.

# Check the installation
limecode --json schema
limecode --json capabilities

# Inspect the running editor
limecode --json status
limecode --json windows
limecode --json tabs

# Open a file
limecode open ~/Documents/notes.toml
limecode new

# Read or edit the active document
limecode get-text --document 1
limecode insert "Hello, LimeCode!" --document 1 --offset 0
limecode find "TODO" --document 1
limecode replace-all "draft" "published" --document 1
limecode undo --document 1
limecode save 1

Use --json for one response per command, or pipe newline-delimited requests with --jsonl for scripts and agents.

MCP / IDE AGENTS

Connect an agent
in one config.

After installing the MCP package, add this server entry to Claude Desktop or your MCP-compatible IDE. Restart the client after saving the configuration.

{
  "mcpServers": {
    "limecode": {
      "command": "/usr/local/libexec/limecode-mcp-server"
    }
  }
}

Keep the website edition of LimeCode running while the agent works. The server forwards the same commands as the CLI and preserves unsaved text, undo history, selection, and revision checks.

QUICK ANSWERS

Before you
start working.

Which package should I download?

Choose Complete for a new setup. Choose App when you only need the editor. Add CLI and MCP separately when you want automation.

Why does CLI say automation is unavailable?

The App Store build is isolated from automation. Install and launch the website edition, then run the CLI or MCP command again.

How do I verify a download?

Download SHA256SUMS and run shasum -a 256 -c SHA256SUMS in the folder containing the packages.
