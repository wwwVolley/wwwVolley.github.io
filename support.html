Common questions

Files do not open?
Use File > Open or Finder's Open With menu. The App Store edition can access files selected through macOS panels.

Automation is unavailable?
CLI and MCP are part of the website edition and are not included in the App Store edition.

Need to report a problem?
Please include your macOS version, LimeCode version, reproduction steps, and a sanitized log. Do not include document contents, passwords, or private keys.
